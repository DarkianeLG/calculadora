Calculadora Simples

Este projeto consiste em uma calculadora simples desenvolvida utilizando HTML, CSS e JavaScript. A interface permite realizar operações matemáticas básicas como adição, subtração, multiplicação e divisão.

🎯 Funcionalidades

Exibição dinâmica dos números e operações.

Suporte para operações básicas: +, -, ×, ÷.

Tratamento para evitar divisão por zero.

Botão para limpar os valores e reiniciar o cálculo.

Interface responsiva para diferentes tamanhos de tela.

Estilização moderna e interativa.

📌 Tecnologias Utilizadas

HTML5: Estrutura da calculadora.

CSS3: Estilização e responsividade.

JavaScript: Lógica para manipulação de eventos e cálculos.

🚀 Como Executar o Projeto

1- Clone este repositório:

git clone https://github.com/seu-usuario/calculadora.git

2- Acesse a pasta do projeto:

cd calculadora

3- Abra o arquivo index.html em um navegador.
